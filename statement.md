# Project Statement

## Project Title
Hotel Management System

## Problem Statement
Manual hotel management can make room allocation, guest registration, booking,
check-in/check-out, billing, and reporting difficult to organize. This project
provides a simple Python-based system to manage these activities through a
menu-driven application.

## Scope
The system manages room information, guest records, room bookings,
check-in/check-out, billing, and basic hotel reports. Data is stored locally
using JSON files.

## Target Users
- Small hotel reception staff
- Hotel administrators
- Students learning Python programming and software development

## High-Level Features
1. Room availability management
2. Guest registration and search
3. Room booking
4. Check-in and check-out
5. Bill generation
6. Hotel reports
7. Input validation and error handling
